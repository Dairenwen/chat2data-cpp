# Chat2Data MySQL 数据库建表操作

## 1. 准备建表脚本

在宿主机终端执行以下命令。这里以数据库名 `chat2data` 为例，如果已有目标数据库，将数据库名替换为实际名称。

首先进入项目目录：

```bash
cd /home/drw/workspace/bite-dev-environment/dev-environment/workspace/chat2data-cpp/chat2data
```

将生成的 [建表脚本](/home/drw/workspace/bite-dev-environment/dev-environment/workspace/chat2data-cpp/chat2data/data/sql/create_tables.sql) 复制到 MySQL 容器：

```bash
docker cp data/sql/create_tables.sql mysql-service:/tmp/chat2data-create-tables.sql
```

## 2. 连接 MySQL 数据库

在宿主机终端执行：

```bash
docker exec -it mysql-service mysql -u root -p --default-character-set=utf8mb4
```

按照提示输入 MySQL root 用户密码。

## 3. 创建数据库并执行建表脚本

进入 MySQL 命令行后，依次执行：

```sql
-- 创建数据库，数据库已存在时不会重新创建。
CREATE DATABASE IF NOT EXISTS chat2data DEFAULT CHARACTER SET utf8mb4;

-- 选择目标数据库。
USE chat2data;

-- 执行建表脚本。
SOURCE /tmp/chat2data-create-tables.sql;
```

## 4. 验证建表结果

执行以下 SQL 命令，查看生成的表及其结构：

```sql
-- 查看数据库中的所有表。
SHOW TABLES;

-- 查看用户表结构。
SHOW CREATE TABLE tbl_user;

-- 查看会话表结构。
SHOW CREATE TABLE tbl_session;
```
