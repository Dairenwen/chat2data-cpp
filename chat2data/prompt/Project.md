# chat2Data 项目介绍

## 1. 项目简介

chat2Data 项目是一款基于 C++17 实现的微服务项目，该项目将 LLM 与数据分析相结合，让用户能够通过自然语言操作 Excel 文件以及数据库，让没有技术背景的人也能通过自然语言查询和分析数据。当前项目处于开发骨架阶段，各子服务尚未实现，下文描述的是规划设计。

## 2. 项目架构

chat2Data 项目采用微服务架构，总共拆分为 7 个子服务：

1. **网关子服务**：前端访问唯一入口，接收浏览器请求，并进行鉴权、协议转换、负载均衡，将请求分发给其他子服务。
2. **用户子服务**：提供用户信息的获取、修改、插入、删除等各项操作。
3. **文件子服务**：提供文件上传、下载、删除、文件列表获取、文件预览、文件存储管理等操作。
4. **Excel 解析子服务**：负责 Excel 文件解析。
5. **存储服务**：负责数据库连接、表结构查询、SQL 执行和 Excel 数据导入等。
6. **AI 子服务**：负责和模型交互，以及聊天会话、聊天消息管理。
7. **通知子服务**：负责发送验证码邮件及其他邮件通知。

## 3. 各子服务涉及的功能

### 3.1 网关子服务

通过 `cpp-httplib` 库搭建网关服务器（HTTP 服务器），实现 30 个 HTTP 接口处理浏览器请求。

通过 `libSource/cpp-service-kit` 提供的服务器监控模块实现服务发现。

通过 `libSource/cpp-service-kit` 提供的 RPC 模块实现负载均衡以及 RPC 调用。

### 3.2 用户子服务

提供用户信息的获取、修改、插入、删除等各项操作。

设计的业务功能如下：

1. 检测用户昵称是否唯一
2. 检测邮箱是否唯一
3. 用户注册
4. 昵称密码登录
5. 邮箱登录
6. 会话登录
7. 获取验证码
8. 退出登录
9. 获取个人信息

### 3.3 文件子服务

提供文件上传、下载、删除、文件列表获取、文件预览、文件存储管理等操作。

设计的业务功能如下：

1. 上传文件信息
2. 获取文件信息
3. 上传文件
4. 下载文件
5. 删除文件
6. 预览 Excel 表格
7. 获取文件列表信息
8. 关联文件和聊天会话
9. 上传 SQLite 文件

### 3.4 Excel 解析子服务

负责 Excel 文件解析，将解析后的 worksheet 表结构以及表数据返回给上层文件子服务，文件子服务会将其存入数据库。

该子服务属于内部服务，在 Excel 上传流程中由文件子服务调用。

设计的业务功能如下：

1. 解析 Excel 文件所有 worksheet。
2. 提取 Excel 文件中每个 worksheet 的表结构和数据。

### 3.5 存储服务

负责数据库连接、表结构查询、SQL 执行和 Excel 数据导入等。用户、文件及业务会话元数据分别由对应业务服务管理；ModelBridge 管理模型会话和消息，配置持久化后存入 SQLite。

设计的业务功能如下：

1. 建立数据库连接
2. 关闭数据库连接
3. 获取数据库表列表
4. 获取表数据
5. 获取指定连接的临时表列表

### 3.6 AI 子服务

负责和模型交互，以及聊天会话、聊天消息管理。

设计的业务功能如下：

1. 获取支持模型列表
2. 新建会话
3. 给模型发送消息
4. 获取会话列表
5. 获取历史会话
6. 删除会话

### 3.7 通知子服务

负责发送验证码邮件及其他邮件通知。

该子服务不与网关通信，专门用于为用户子服务提供发送验证码功能，以及为 AI 子服务提供发送邮件功能。

设计的业务功能如下：

1. 发送验证码
2. 发送 AI 结果邮件

## 4. 数据流向

用户在前端页面中，可以选择智能 Excel 助手页面，通过自然语言方式操作 Excel 文件；通过选择智能 DB 助手页面，通过自然语言方式操作数据库。

规划支持 MySQL 和 SQLite 两种数据库。

### 4.1 智能 Excel 助手数据流向

用户通过自然语言操作 Excel 时，完整的流程如下：

1. 用户选择模型并创建聊天会话，然后上传 Excel。
2. 网关将请求转发给文件子服务。
3. 文件子服务调用 Excel 子服务进行文件解析，解析出所有 worksheet 以及表结构和数据。
4. 文件子服务调用存储子服务将数据存入数据库。
5. 文件子服务将文件存入 FastDFS 存储系统。
6. 文件子服务处理上传文件完成，将结果返回给网关。
7. 网关将上传文件响应返回给浏览器。
8. 将文件与聊天会话关联，按需预览解析后的数据。
9. 用户提问。
10. 网关将请求转发给 AI 子服务。
11. AI 子服务调用数据库子服务获取表结构和采样数据。
12. AI 子服务将表结构 + 采样数据 + 用户问题 + 提示词模板构建完整提示词。
13. 将完整提示词发送给大模型。
14. 大模型生成相应 SQL。
15. AI 子服务调用存储子服务执行 SQL 语句。
16. AI 子服务将 SQL 执行结果发送给大模型。
17. 大模型生成总结 + 可视化数据。
18. AI 子服务通过流式通道将结果返回给网关。
19. 网关通过 SSE 将结果返回给浏览器。
20. 浏览器进行最终结果渲染。

### 4.2 智能 DB 助手数据流向

用户通过自然语言操作 MySQL 或 SQLite 数据库时，主要流程如下：

1. 用户填写 MySQL 连接信息，或上传 SQLite 文件。
2. 发送连接数据库请求。
3. 网关将连接数据库请求转给存储子服务。
4. 存储子服务根据数据库类型连接对应数据库。
5. 存储子服务返回连接 ID，网关将其返回浏览器。
6. 浏览器使用连接 ID 请求表列表，网关转发请求并返回结果供浏览器渲染。
7. 浏览器发送获取指定表表数据请求。
8. 网关将请求转发给存储子服务。
9. 存储子服务根据表名获取表数据。
10. 存储子服务将表数据返回给网关。
11. 网关将表数据返回给浏览器渲染。
12. 用户选择模型、创建聊天会话并提问。
13. 网关将请求转发给 AI 子服务。
14. AI 子服务调用数据库子服务获取表结构和采样数据。
15. AI 子服务将表结构 + 采样数据 + 用户问题 + 提示词模板构建完整提示词。
16. 将完整提示词发送给大模型。
17. 大模型生成相应 SQL。
18. AI 子服务调用存储子服务执行 SQL 语句；修改类操作先备份原表，再在临时表中执行。
19. AI 子服务将 SQL 执行结果发送给大模型。
20. 大模型生成分析总结和可视化内容。
21. AI 子服务将结果流式返回网关，网关通过 SSE 发送给浏览器。
22. 浏览器展示分析结果。
