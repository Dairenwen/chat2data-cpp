# Chat2ExcelEasy 项目文档

## 项目介绍

Chat2ExcelEasy 是一个基于人工智能的Excel数据分析助手系统。该项目通过结合现在Web技术与AI大语言模型，为用户提供智能化的Excel数据分析服务。用户只需上传Excel文件并提出问题，系统就可自动解析文件内容，并通过AI模型生成专业的数据分析报告和建议。

## 数据流向

1. 用户通过浏览器上传Excel文件
2. 服务器接收文件并保存到本地，并生成唯一的文件标识符给前端
3. 用户发送问题
4. 服务器根据文件标识符解析Excel文件内容
5. 将解析后的Excel数据序列化之后，结合用户问题以及提示词模板，生成完整的提示词
6. ChatSDK负责将提示词发送给模型
7. 模型返回流式分析结果
8. 服务器将模型返回的结果，以SSE的方式实时推送给前端
9. 浏览器渲染并展示分析结果

## 核心模块

### Excel解析器

- 负责读取并解析Excel文件内容，目前仅支持.xlsx格式
- 支持获取Excel文件中所有worksheet名称
- 支持解析Excel中指定worksheet中所有表数据

### HTTP服务器

- 提供HTTP服务器搭建，服务器启动和停止，以及服务器运行状态的检测
- 提供文件上传接口，接收用户上传的Excel文件，并保存到本地
- 负责根据用户问题以及Excel文件内容，生成完整的提示词
- 提供发送消息的接口，接收用户发送的问题，借助ChatSDK将消息发送给模型，大模型返回的流式结果，通过SSE的方式实时推送给前端

### 前端页面

前端页面提供友好的用户体验，用户可以通过浏览器上传文件，输入需求，并展示模型返回的结果

## 技术栈和依赖库

- **编程语言**：C++17标准
- **依赖库**：
  - **cpp-httplib**：用于搭建HTTP服务器，处理HTTP请求和响应
  - **ChatSDK**：用于和大模型交互，发送消息并接收流式结果
  - **OpenXLSX**：用于解析Excel文件解析
  - **bite_scaffold**：用于json序列化和反序列化、文件读写、日志系统、gflags参数解析等
- **项目构建**：使用CMake构建项目
